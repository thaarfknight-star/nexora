# Nexora

**Nexora** is a floating Dynamic Island shell replacement for **Windows 10 and Windows 11**, built with **Tauri v2**, **Rust**, and **React**. Designed to modernize the desktop experience, Nexora provides a sleek, responsive floating island that replaces or augments the traditional Windows taskbar with real-time system telemetry, media controls, and customizable visual themes.

## Key Features

- **Dynamic Island**: A smooth, interactive floating pill for Windows 10/11 that expands on demand to display live status, quick controls, and notifications.
- **Safe Taskbar Replacement & Watchdog**: Safely replaces the default Windows taskbar while running a dedicated Watchdog process to ensure system stability and automatic taskbar restoration if needed.
- **GSMTC Media Controls**: Native integration with Windows Global System Media Transport Controls (GSMTC) for seamless playback control, track metadata, and album art across supported media apps.
- **System Monitoring**: Built-in real-time system monitoring to keep track of key hardware and performance metrics directly from the island.
- **6 Themes (including Liquid Glass)**: Choose from 6 carefully crafted themes—featuring the signature **Liquid Glass** aesthetic—to match your desktop setup.
- **Auto-Update Engine**: Integrated automatic update engine to keep Nexora up to date with the latest features and fixes effortlessly.

## Tech Stack

- **Core / Backend**: Rust & Tauri v2
- **Frontend**: React
- **Platform**: Windows 10 / Windows 11
